# Cadence

Private personal life scoreboard — Vite + React. Read-only UI; day metrics are updated via git (voice dump → Cursor → commit), then shown on Netlify.

## Local

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Build / Netlify

```bash
npm run build
```

Netlify: build `npm run build`, publish `dist` (see `netlify.toml`).

No API keys required.
